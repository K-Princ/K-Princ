## 🚀 Featured Projects

### 1. 👕 Fashion Image Classification – Transfer Learning

**Tech Stack:** Python, TensorFlow, Keras, Xception

- Adapted a pretrained Xception network for 10-class clothing image classification.
- Developed a custom classification head while freezing the pretrained base network.
- Experimented with learning rates, dropout, hidden-layer sizes, and image augmentation.
- Achieved **89.8% test accuracy**.

### 2. 💳 Credit Risk Scoring

**Tech Stack:** Python, Pandas, Scikit-learn, XGBoost

- Analyzed 4,455 loan records with 14 features.
- Benchmarked Decision Tree, Random Forest, and XGBoost classifiers.
- Evaluated 64 hyperparameter configurations.
- Achieved **0.795 validation AUC and 0.802 held-out test AUC** using XGBoost.

### 3. 📉 Customer Churn Prediction

**Tech Stack:** Python, Pandas, Scikit-learn, FastAPI, Pydantic

- Analyzed customer data containing 7,043 records and 21 features.
- Used mutual information to identify important churn predictors.
- Developed a Logistic Regression model.
- Achieved **0.858 test ROC AUC**.
- Built a FastAPI prediction endpoint with Pydantic input validation.

### 4. ✈️ Airline Passenger Satisfaction Prediction

**Tech Stack:** Python, Pandas, Scikit-learn

- Developed classification pipelines for airline passenger satisfaction.
- Applied categorical feature encoding and feature scaling.
- Compared Logistic Regression and Decision Tree models.
- Achieved **0.921 validation ROC AUC**.

### 5. 🏠 Car Price & House Price Prediction

**Tech Stack:** Python, NumPy, Pandas, Machine Learning

- Implemented Linear Regression from scratch using NumPy.
- Applied the normal equation and L2 regularization.
- Performed feature engineering and one-hot encoding.
- Achieved test RMSE of **0.452 for car prices and 0.346 for house prices** on log-transformed targets.
